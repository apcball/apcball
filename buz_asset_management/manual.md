# คู่มือการใช้งาน BUZ Asset Management

โมดูลบริหารทรัพย์สินถาวร (Fixed Asset) สำหรับ Odoo 17 ของ Mogen Co. ครอบคลุมตั้งแต่ขึ้นทะเบียนทรัพย์สิน ตัดค่าเสื่อมราคา โอนย้าย ซ่อมบำรุง ประกัน/รับประกัน ตรวจนับ ไปจนถึงจำหน่ายทรัพย์สินและกระทบยอดกับบัญชีแยกประเภท (GL)

> เมนูหลักอยู่ที่ **Asset Management** ชื่อเมนูเป็นภาษาอังกฤษ ส่วนชื่อปุ่มและฟิลด์ในฟอร์มเป็นภาษาไทย คู่มือนี้ใช้ชื่อตามที่เห็นบนหน้าจอ

## 1. ภาพรวมและแนวคิดสำคัญ

### โครงสร้างเมนู

| เมนู | เมนูย่อย | ใช้ทำอะไร |
|---|---|---|
| **Dashboard** | | ภาพรวมตัวเลขและกราฟ |
| **Asset Register** | | ทะเบียนทรัพย์สิน |
| **Accounting** | Depreciation, Disposal | ตารางค่าเสื่อมราคา ลงบัญชี/กลับรายการ และการจำหน่าย |
| **Operations** | Transfers, Maintenance, Warranty / Insurance, Audit | งานปฏิบัติการ |
| **Reports** | Register & Value, Depreciation & Accounting, Operations | รายงาน |
| **Configuration** | Asset Categories, Locations | ข้อมูลตั้งต้น |

### สามสถานะที่ต้องแยกให้ออก

ทรัพย์สินหนึ่งรายการมี **สถานะ 3 ชุด** ที่เปลี่ยนแยกกัน:

| สถานะ | ค่าที่เป็นไปได้ |
|---|---|
| **สถานะการอนุมัติ** | ร่าง → ส่งขออนุมัติแล้ว → อนุมัติแล้ว |
| **สถานะการใช้งาน** | ยังไม่เริ่มใช้งาน → อยู่ระหว่างใช้งาน ↔ อยู่ระหว่างซ่อมบำรุง (รวมถึง สูญหาย, อยู่ระหว่างยืม, จำหน่ายแล้ว) |
| **สถานะทางบัญชี** | ยังไม่บันทึกเป็นสินทรัพย์ → บันทึกเป็นสินทรัพย์แล้ว → จำหน่ายแล้ว |

### หลักการบัญชีที่โมดูลยึดถือ

- **ทะเบียนทรัพย์สินไม่สร้างรายการบัญชีเอง** ราคาทุนอยู่ใน GL อยู่แล้ว (จากใบแจ้งหนี้ผู้ขาย ยอดยกมา หรือรายการปรับปรุง) การ "บันทึกเป็นสินทรัพย์" เป็นการยืนยันสถานะในทะเบียนเท่านั้น
- **ค่าเสื่อมราคา** เป็นแบบเส้นตรง รายเดือน ตัดเต็มเดือน (เดือนที่เริ่มใช้งานนับเป็นงวดที่ 1 ไม่คิดตามสัดส่วนวัน) วันที่ลงบัญชีคือวันสิ้นเดือนของแต่ละงวด งวดสุดท้ายรับเศษที่เหลือ
- **ตารางค่าเสื่อมเป็นแผน** ไม่ใช่ยอดบัญชี มูลค่าตามบัญชีและค่าเสื่อมสะสมนับเฉพาะงวดที่ **ลงบัญชีแล้ว** เท่านั้น
- **ไม่แก้หรือลบรายการบัญชีที่ post แล้ว** การแก้ไขทำผ่านการกลับรายการและคำนวณตารางใหม่
- **เคารพวันที่ล็อกบัญชี** ถ้าวันที่ของงวดอยู่ในช่วงที่ล็อก ระบบจะไม่ลงบัญชีให้ และไม่เลื่อนวันที่ให้เอง งวดนั้นจะถูกตั้งเป็น "ข้อยกเว้น" พร้อมข้อความอธิบาย

## 2. บทบาทและสิทธิ์

โมดูลมี 5 กลุ่มสิทธิ์ (ตั้งที่ Settings → Users → ช่อง Asset Management)

| กลุ่ม | ทำอะไรได้ |
|---|---|
| **Asset User** | ดูทะเบียนทรัพย์สิน ดูแดชบอร์ดและรายงานทั่วไป บันทึกผลตรวจนับ รับทราบการโอนย้าย สแกน QR |
| **Asset Officer** | (รวมสิทธิ์ User) สร้างและแก้ไขทรัพย์สิน ส่งขออนุมัติ เริ่มใช้งาน สร้างทรัพย์สินจากใบแจ้งหนี้ ขอโอนย้าย/ดำเนินการโอนย้าย จัดการงานซ่อม ประกัน สร้างรอบตรวจนับและเริ่มตรวจนับ ระบุการแก้ไขผลตรวจ ขอจำหน่าย |
| **Asset Manager** | (รวมสิทธิ์ Officer) อนุมัติทรัพย์สิน รีเซ็ตเป็นร่าง อนุมัติ/ปฏิเสธการโอนย้าย อนุมัติการจำหน่าย ปิด/ยกเลิกรอบตรวจนับ |
| **Asset Accountant** | (รวมสิทธิ์ User) บันทึกเป็นสินทรัพย์ คำนวณตารางค่าเสื่อม คำนวณตารางที่เหลือใหม่ ใช้รายงานกระทบยอด GL และ Roll-forward |
| **Asset Accounting Manager** | (รวมสิทธิ์ Accountant) **ลงบัญชีและกลับรายการค่าเสื่อมราคา ลงบัญชีการจำหน่าย** เปิด/ปิดการลงบัญชีค่าเสื่อมอัตโนมัติ |

ข้อควรรู้:

- Asset Manager **ไม่ได้** รวมสิทธิ์ Accountant และ Accountant **ไม่ได้** รวมสิทธิ์ Officer ถ้าคนเดียวต้องทำทั้งสองด้านต้องกำหนดสองกลุ่ม
- ระบบตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ ปุ่มที่มองไม่เห็นไม่ใช่กลไกป้องกันเพียงอย่างเดียว
- ข้อมูลแยกตามบริษัท (multi-company) ผู้ใช้เห็นเฉพาะทรัพย์สินของบริษัทที่เลือกไว้

## 3. การตั้งค่าก่อนใช้งาน

ผู้ดูแลระบบและฝ่ายบัญชีตั้งค่าตามลำดับนี้ก่อนขึ้นทะเบียนทรัพย์สินจริง

### 3.1 หมวดหมู่ทรัพย์สิน (Configuration → Asset Categories)

หมวดหมู่เป็นตัวกำหนดบัญชีและค่าเริ่มต้นของทรัพย์สินทุกรายการ ฟิลด์สำคัญ:

| ฟิลด์ | ความหมาย |
|---|---|
| ชื่อ / รหัส / บริษัท | ระบุบริษัทด้วยถ้าจะผูกบัญชีหรือสมุดรายวัน (หมวดหมู่ที่ไม่ระบุบริษัทผูกบัญชีไม่ได้) |
| รูปแบบการติดตาม | รายตัว หรือ แบบกลุ่ม |
| ต้องระบุแผนก / ต้องมีป้าย QR | ข้อกำหนดของหมวดหมู่ |
| วิธีคิดค่าเสื่อมราคา / ความถี่ | ปัจจุบันรองรับเส้นตรง รายเดือน |
| อายุการใช้งาน (เดือน) | ค่าเริ่มต้นของทรัพย์สินในหมวดนี้ |
| บัญชีสินทรัพย์ถาวร | บัญชีราคาทุน |
| บัญชีค่าเสื่อมราคาสะสม | เครดิตของรายการค่าเสื่อม |
| บัญชีค่าใช้จ่ายค่าเสื่อมราคา | เดบิตของรายการค่าเสื่อม |
| บัญชีกำไร/ขาดทุนจากการจำหน่าย | ใช้ตอนจำหน่าย |
| บัญชีพักการจำหน่าย | ใช้เมื่อจำหน่ายแบบขายและผูกใบแจ้งหนี้ขาย (ดู [บทที่ 12](#12-จำหน่ายทรัพย์สิน)) |
| สมุดรายวันค่าเสื่อมราคา | สมุดรายวันที่ลงรายการค่าเสื่อมและจำหน่าย |

> **ต้องตั้งบัญชีและสมุดรายวันให้ครบก่อน** มิฉะนั้นจะบันทึกเป็นสินทรัพย์หรือลงบัญชีค่าเสื่อมไม่ได้ และบัญชีต้องเป็นของบริษัทเดียวกับทรัพย์สิน

### 3.2 สถานที่ตั้ง (Configuration → Locations)

สร้างสถานที่เป็นลำดับชั้น (พื้นที่ → อาคาร → ชั้น → ห้อง → ที่จัดเก็บ) ผูกกับคลังสินค้าหรือ stock location ได้ ใช้ในการโอนย้ายและกำหนดขอบเขตตรวจนับ

### 3.3 ภาษีซื้อที่ขอคืนไม่ได้ (ถ้ามี)

ที่ Accounting → Configuration → Taxes เปิดตัวเลือก **ภาษีซื้อขอคืนไม่ได้ (รวมเป็นต้นทุนทรัพย์สิน)** ในภาษีซื้อแบบเปอร์เซ็นต์ที่ต้องการ ยอดภาษีของรายการที่ใช้ภาษีนี้จะถูกรวมเป็นราคาทุนตอนสร้างทรัพย์สินจากใบแจ้งหนี้ ภาษีนี้ต้องลงบัญชีนอกบัญชีภาษี (ไม่ใช้ในการปิดภาษี) เพื่อให้ยอดตรงกับ GL

### 3.4 ลงบัญชีค่าเสื่อมอัตโนมัติ (ไม่บังคับ)

ที่หน้าบริษัท (Settings → Companies) ฟิลด์ **ลงบัญชีค่าเสื่อมราคาอัตโนมัติ** (เห็นและแก้ได้เฉพาะ Asset Accounting Manager) **ปิดไว้เป็นค่าเริ่มต้น** ระบบไม่ลงบัญชีเองจนกว่าฝ่ายบัญชีเปิดใช้ ดูรายละเอียดการทำงานในหัวข้อ [6.4](#64-การลงบัญชีอัตโนมัติ-cron)

### 3.5 ข้อกำหนดทางเทคนิค

ต้องติดตั้ง Python package `xlsxwriter` บนเซิร์ฟเวอร์ (ใช้ส่งออก Excel ของแดชบอร์ด)

## 4. ขึ้นทะเบียนทรัพย์สิน

มี 2 ทาง

### 4.1 สร้างจากใบแจ้งหนี้ผู้ขาย (แนะนำ)

1. เปิดใบแจ้งหนี้ผู้ขาย (Vendor Bill) ที่ **Post แล้ว**
2. กดปุ่ม **สร้างทรัพย์สิน** ที่แถบปุ่มด้านบน (เห็นเฉพาะ Asset Officer ขึ้นไป)
3. ในหน้าต่างที่เปิดขึ้น แต่ละแถวคือหนึ่งทรัพย์สิน ระบุ **หมวดหมู่** (จำเป็น) ชื่อทรัพย์สิน และ **ราคาทุนที่จัดสรร**
4. ถ้ารายการเดียวต้องแตกเป็นหลายทรัพย์สิน ให้เพิ่มแถวแล้วเลือกรายการใบแจ้งหนี้เดียวกัน แบ่งราคาทุนตามต้องการ
5. กด **สร้างทรัพย์สิน**

กฎที่ระบบบังคับ:

- นำมาใช้ได้เฉพาะรายการสินค้า/บริการของใบแจ้งหนี้ผู้ขายที่ post แล้ว (ไม่รวมบรรทัดภาษี เจ้าหนี้ หรือใบลดหนี้)
- ยอดจัดสรรรวมต่อรายการต้องไม่เกินยอดที่ใช้ได้ (ยอดบรรทัดบวกภาษีที่ขอคืนไม่ได้ ถ้ามี) ถ้าเกินจะถูกปฏิเสธ
- ใบแจ้งหนี้ที่ถูกใช้สร้างทรัพย์สินแล้ว **ตั้งกลับเป็นร่างหรือยกเลิกไม่ได้** ให้ใช้ใบลดหนี้หรือกลับรายการแทน
- ยอดเป็นสกุลเงินบริษัท (ตามที่ลง GL จริง) กรณีใบแจ้งหนี้เป็นเงินตราต่างประเทศ
- ถ้าลบทรัพย์สินที่ยังเป็นร่าง ยอดที่จัดสรรจะถูกคืนให้จัดสรรใหม่ได้

### 4.2 บันทึกเอง

Asset Register → **New**

| แท็บ | ข้อมูลที่กรอก |
|---|---|
| **ภาพรวม** | ชื่อ หมวดหมู่ บริษัท รายละเอียด หมายเลขเครื่อง ผู้ผลิต รุ่น บาร์โค้ด ทรัพย์สินหลัก (กรณีเป็นส่วนประกอบ) |
| **การได้มา** | ประเภทที่มา (บันทึกเอง, ยอดยกมา, ได้รับบริจาค, ก่อสร้างเอง, อื่นๆ) **เหตุผล/เอกสารอ้างอิง** วันที่ได้มา **วันที่เริ่มใช้งาน** วันที่เริ่มคิดค่าเสื่อมราคา (ถ้าต่างจากวันเริ่มใช้งาน) |
| **บัญชี** | **ราคาทุน** มูลค่าซาก อายุการใช้งาน (เดือน) ระบบคำนวณ "มูลค่าที่ต้องคิดค่าเสื่อมราคา" = ราคาทุน − มูลค่าซาก |
| **ผู้ถือครองและสถานที่** | แผนก ผู้ถือครอง สถานที่ตั้ง |

- รหัสทรัพย์สินสร้างให้อัตโนมัติ (เลขรันนิ่งต่อบริษัท) แก้ไม่ได้
- มูลค่าซากต้องไม่ติดลบและไม่เกินราคาทุน ถ้ามีมูลค่าที่ต้องคิดค่าเสื่อม อายุการใช้งานต้องมากกว่าศูนย์
- **การบันทึกเองไม่สร้างรายการบัญชี** ต้องมีรายการราคาทุนใน GL อยู่แล้ว และควรระบุเหตุผล/เอกสารอ้างอิงไว้

## 5. วงจรชีวิตของทรัพย์สิน

```
ร่าง ──ส่งขออนุมัติ──▶ ส่งขออนุมัติแล้ว ──อนุมัติ──▶ อนุมัติแล้ว
 (Officer)               (Manager)

อนุมัติแล้ว ──เริ่มใช้งาน──▶ อยู่ระหว่างใช้งาน ──บันทึกเป็นสินทรัพย์──▶ บันทึกเป็นสินทรัพย์แล้ว
             (Officer)                       (Accountant)

บันทึกเป็นสินทรัพย์แล้ว ──ตัดค่าเสื่อม/โอนย้าย/ซ่อม/ตรวจนับ──▶ ... ──จำหน่าย──▶ จำหน่ายแล้ว
```

ปุ่มบนฟอร์มทรัพย์สิน

| ปุ่ม | ผู้ใช้ | เงื่อนไข |
|---|---|---|
| **ส่งขออนุมัติ** | Officer | สถานะอนุมัติ = ร่าง |
| **อนุมัติ** | Manager | ส่งขออนุมัติแล้ว |
| **เริ่มใช้งาน** | Officer | อนุมัติแล้ว และต้องระบุ **วันที่เริ่มใช้งาน** |
| **บันทึกเป็นสินทรัพย์** | Accountant | อนุมัติแล้ว อยู่ระหว่างใช้งาน และหมวดหมู่ตั้งบัญชีครบ |
| **คำนวณตารางค่าเสื่อม** | Accountant | ใช้คำนวณครั้งแรก |
| **คำนวณตารางที่เหลือใหม่** | Accountant | หลังบันทึกเป็นสินทรัพย์แล้ว (ดู [6.5](#65-คำนวณตารางที่เหลือใหม่)) |
| **แจ้งงานบำรุงรักษา** | Officer | อนุมัติแล้ว ยังไม่จำหน่าย |
| **โอนย้าย** | Officer | อนุมัติแล้ว ยังไม่จำหน่าย |
| **รีเซ็ตเป็นร่าง** | Manager | ใช้ได้เฉพาะทรัพย์สินที่ยังไม่เริ่มใช้งานและยังไม่บันทึกเป็นสินทรัพย์ |

ข้อควรรู้:

- ฟิลด์สถานะแก้ตรงๆ ไม่ได้ ต้องผ่านปุ่มเท่านั้น (รวมถึงผ่าน RPC)
- ทรัพย์สินที่อนุมัติแล้ว **ผู้ถือครอง แผนก และสถานที่ แก้ตรงๆ ไม่ได้** ต้องใช้การโอนย้ายเพื่อเก็บประวัติ
- ลบได้เฉพาะทรัพย์สินที่เป็น **ร่าง** นอกนั้นให้เก็บถาวร (Archive)

## 6. ค่าเสื่อมราคา

### 6.1 คำนวณตาราง

1. ทรัพย์สินต้องอนุมัติ เริ่มใช้งาน และบันทึกเป็นสินทรัพย์แล้ว
2. ที่ฟอร์มทรัพย์สิน กด **คำนวณตารางค่าเสื่อม** (Accountant)
3. ดูผลที่แท็บ **ตารางค่าเสื่อมราคา**: ลำดับ เริ่มงวด วันที่ตัดค่าเสื่อม จำนวนที่วางแผนไว้ คงเหลือหลังงวด สถานะ

ตัวอย่าง: ราคาทุน 13,000 ซาก 1,000 อายุ 12 เดือน เริ่มใช้งาน 15 มีนาคม → ฐาน 12,000 → งวดละ 1,000 งวดที่ 1 = มีนาคม (ตัดเต็มเดือน) ลงวันที่ 31 มีนาคม

> คำนวณใหม่ด้วยปุ่มนี้ได้ **ก่อนมีงวดที่ลงบัญชี** เท่านั้น หลังจากนั้นใช้ [คำนวณตารางที่เหลือใหม่](#65-คำนวณตารางที่เหลือใหม่)

### 6.2 ลงบัญชีค่าเสื่อม

เมนู **Accounting → Depreciation** (รายการตารางค่าเสื่อมของทุกทรัพย์สิน กรองด้วย วางแผนไว้ / ลงบัญชีแล้ว ฯลฯ) ผู้ที่ลงบัญชีได้คือ **Asset Accounting Manager**

- กดปุ่ม **ลงบัญชี** ที่แถว ระบบสร้างรายการบัญชี: เดบิต ค่าใช้จ่ายค่าเสื่อมราคา / เครดิต ค่าเสื่อมราคาสะสม
- ต้องลงตามลำดับงวด ลงงวดที่ 3 ก่อนงวดที่ 2 ไม่ได้
- ลงล่วงหน้าไม่ได้ (วันที่ของงวดต้องถึงแล้ว)
- กดซ้ำไม่สร้างรายการซ้ำ
- ถ้าวันที่ของงวดอยู่ในช่วงล็อกบัญชี หรือนโยบายวันที่ของบริษัทไม่อนุญาต งวดจะเป็น **ข้อยกเว้น** พร้อมข้อความ หลังปลดล็อกหรือแก้ปัญหาแล้วกด **ลงบัญชี** ใหม่ได้

สถานะของงวด: วางแผนไว้ → ลงบัญชีแล้ว → กลับรายการแล้ว (นอกจากนี้มี ข้อยกเว้น และ ยกเลิกแล้ว เมื่อทรัพย์สินถูกจำหน่าย)

### 6.3 กลับรายการ

ในรายการเดียวกัน กดปุ่ม **กลับรายการ** ที่งวดที่ลงบัญชีแล้ว (Asset Accounting Manager)

- ระบบสร้างรายการกลับและผูกกับงวด งวดเปลี่ยนเป็น **กลับรายการแล้ว** รายการเดิมยังอยู่
- ใช้ปุ่ม Reverse มาตรฐานของ Odoo ที่หน้ารายการบัญชีก็ได้ ผลเหมือนกัน (ระบบ sync สถานะงวดให้) แต่ต้องมีสิทธิ์ Asset Accounting Manager และรายการกลับต้อง post ทันที
- รายการบัญชีของทรัพย์สิน (ค่าเสื่อม รายการกลับ และการจำหน่าย) **ตั้งกลับเป็นร่าง ยกเลิก หรือลบไม่ได้**
- รายการบัญชี **การจำหน่าย** กลับรายการไม่ได้ (ยังไม่มีขั้นตอนคืนสถานะทรัพย์สิน)

### 6.4 การลงบัญชีอัตโนมัติ (cron)

เมื่อ Asset Accounting Manager เปิด **ลงบัญชีค่าเสื่อมราคาอัตโนมัติ** ที่บริษัท ระบบจะรันทุกวันและลงงวดที่ถึงกำหนดให้

- ข้ามทรัพย์สินที่ยังไม่พร้อม (ยังไม่อนุมัติ ไม่ได้ใช้งาน หรือยังไม่บันทึกเป็นสินทรัพย์) โดยไม่สร้างข้อยกเว้น
- ถ้าพบปัญหาก่อนลงบัญชี (เช่น หมวดหมู่ไม่มีบัญชี) งวดนั้นเป็น **ข้อยกเว้น** และหยุดทรัพย์สินตัวนั้นในรอบนั้น ทรัพย์สินอื่นยังลงต่อ
- ทรัพย์สินที่มีงวดเป็นข้อยกเว้นค้างอยู่จะถูกข้ามจนกว่าจะมีคนแก้และกดลงบัญชีเอง (cron ไม่ลองซ้ำให้)
- รันซ้ำได้ปลอดภัย ไม่เกิดรายการซ้ำ

ติดตามงวดที่เป็นข้อยกเว้นได้จากแดชบอร์ด/รายการตารางค่าเสื่อม (กรองสถานะ ข้อยกเว้น)

### 6.5 คำนวณตารางที่เหลือใหม่

ใช้เมื่อต้องแก้ตารางหลังมีงวดที่ลงบัญชีแล้ว เช่น กลับรายการงวดที่ผิด หรือแก้ราคาทุน/มูลค่าซาก/อายุการใช้งาน

**ขั้นตอน (Accountant)**

1. (ถ้าจำเป็น) กลับรายการงวดที่ผิด และ/หรือแก้ราคาทุน มูลค่าซาก อายุการใช้งานที่ฟอร์มทรัพย์สิน
2. กด **คำนวณตารางที่เหลือใหม่** แล้วยืนยัน

**ระบบทำอะไร**

- เก็บงวดที่ลงบัญชีแล้ว กลับรายการแล้ว และยกเลิกแล้วไว้เป็นประวัติ
- ลบงวดที่ยังเป็น วางแผนไว้/ข้อยกเว้น แล้วสร้างใหม่ โดยกระจาย **(มูลค่าที่ต้องคิดค่าเสื่อม − ยอดที่ลงบัญชีสุทธิ)** แบบเส้นตรงตามจำนวนเดือนที่เหลือของอายุการใช้งาน นับจากเดือนถัดจากงวดที่ลงบัญชีล่าสุด
- ไม่ลงบัญชีให้ ต้องลงบัญชีเองหรือรอ cron ถ้างวดใหม่ตกในช่วงล็อกบัญชีจะเป็นข้อยกเว้นเมื่อลง

ตัวอย่าง: 12 เดือน เดือนละ 100 ลงบัญชี P1, P2, P3 แล้วกลับรายการ P2 → ยอดสุทธิ 200 เหลือ 1,000 กระจาย 9 เดือน (P4–P12) งวดละ 111.11 งวด P2 คงเป็นประวัติที่ "กลับรายการแล้ว"

**ระบบจะไม่ยอมคำนวณ เมื่อ**

- ทรัพย์สินจำหน่ายแล้ว
- มีงวดเป็นร่างรายการบัญชีค้างอยู่
- ยอดที่ลงบัญชีแล้วเกินมูลค่าที่ต้องคิดค่าเสื่อมใหม่ → ต้องกลับรายการงวดที่เกินก่อน
- อายุการใช้งานหมดแล้วแต่ยังเหลือมูลค่า → ต้องขยายอายุก่อน

## 7. โอนย้ายทรัพย์สิน

เปลี่ยนผู้ถือครอง แผนก หรือสถานที่ของทรัพย์สินที่อนุมัติแล้ว พร้อมเก็บประวัติ

**ขั้นตอน**

1. เริ่มจากปุ่ม **โอนย้าย** ที่ฟอร์มทรัพย์สิน หรือ Operations → Transfers → New
2. ระบุ **วันที่มีผล เหตุผล** และค่าใหม่ (ผู้ถือครองใหม่ แผนกใหม่ สถานที่ใหม่) ระบบบันทึก "ข้อมูลเดิม" ให้อัตโนมัติ
3. **ส่งขออนุมัติ** (Officer) → **อนุมัติ** หรือ **ไม่อนุมัติ** (Manager)
4. **ดำเนินการโอนย้าย** (Officer) ระบบปรับข้อมูลทรัพย์สินและบันทึกใน chatter
5. ผู้รับทรัพย์สินกด **รับทราบ** (Asset User ขึ้นไป) ระบบเก็บผู้รับทราบและเวลา

สถานะ: ร่าง → ส่งขออนุมัติแล้ว → อนุมัติแล้ว → โอนย้ายแล้ว (หรือ ไม่อนุมัติ / ยกเลิก กลับเป็นร่างได้โดย Manager)

กฎ:

- ทรัพย์สินหนึ่งรายการมีใบโอนย้ายที่ยังไม่เสร็จได้ครั้งละหนึ่งใบ
- ต้องมีการเปลี่ยนแปลงอย่างน้อยหนึ่งอย่าง
- ถ้าระหว่างรออนุมัติ ข้อมูลของทรัพย์สินเปลี่ยนไปแล้ว (เช่น มีการโอนย้ายอื่น) ระบบไม่ยอมให้ดำเนินการ ให้ยกเลิกแล้วสร้างใหม่
- โอนย้ายข้ามบริษัทยังไม่รองรับ
- ใบที่โอนย้ายแล้วแก้ไขไม่ได้

## 8. ซ่อมบำรุง

Operations → **Maintenance** หรือปุ่ม **แจ้งงานบำรุงรักษา** ที่ทรัพย์สิน (Officer)

- **ประเภท:** บำรุงรักษาเชิงป้องกัน, ซ่อมแซม, ตรวจสอบ, สอบเทียบ, อื่นๆ
- **ข้อมูลงาน:** รายละเอียดงาน วันที่วางแผน ผู้รับผิดชอบ ผู้ให้บริการ ช่างผู้ดำเนินการ อยู่ในประกัน/รับประกัน เวลาหยุดใช้งาน ผลการดำเนินงาน
- **ค่าใช้จ่าย:** ค่าแรง/ค่าบริการ และรายการอะไหล่ (จำนวน × ราคาต่อหน่วย) ระบบรวมเป็นค่าใช้จ่ายรวม
- **ทำซ้ำทุก (เดือน):** ถ้าระบุ เมื่องานเสร็จ ระบบสร้างกิจกรรมเตือนรอบถัดไปให้ผู้รับผิดชอบ

**ขั้นตอน:** ร่าง → **วางแผน** → **เริ่มดำเนินการ** → **เสร็จสิ้น** (ยกเลิก หรือ กลับเป็นร่างได้)

ข้อควรรู้:

- เมื่อเริ่มดำเนินการ ทรัพย์สินเปลี่ยนเป็น "อยู่ระหว่างซ่อมบำรุง" และกลับเป็น "อยู่ระหว่างใช้งาน" เมื่อเสร็จ
- งานที่เสร็จสิ้นแล้วแก้ไขไม่ได้
- ทรัพย์สินที่ยังไม่อนุมัติหรือจำหน่ายแล้วสร้างงานซ่อมไม่ได้
- **ค่าซ่อมเป็นค่าใช้จ่ายเชิงปฏิบัติการ ไม่ถูกรวมเข้าราคาทุนและไม่ทำให้ทรัพย์สินถูกบันทึกเป็นสินทรัพย์**
- ระบบแจ้งเตือนงานที่วางแผนไว้ล่วงหน้า 7 วัน (ค่าคงที่ของระบบ ปรับไม่ได้จากหน้าจอ) เป็นกิจกรรมถึงผู้รับผิดชอบ ครั้งเดียวต่องาน รันทุกวัน เฉพาะงานที่มีผู้รับผิดชอบ

## 9. การรับประกัน / ประกันภัย

Operations → **Warranty / Insurance** หรือแท็บ **การรับประกัน/ประกันภัย** ที่ทรัพย์สิน (Officer)

| ฟิลด์ | ความหมาย |
|---|---|
| ประเภท | การรับประกัน หรือ ประกันภัย |
| ผู้ให้บริการ/บริษัทประกัน | คู่ค้า |
| เลขที่การรับประกัน/เลขที่กรมธรรม์ | จำเป็น |
| วันที่เริ่ม – วันที่สิ้นสุด | วันสิ้นสุดต้องไม่ก่อนวันเริ่ม |
| ความคุ้มครอง / เงื่อนไข / ทุนประกัน | รายละเอียด |
| ผู้รับผิดชอบการติดตาม | รับกิจกรรมแจ้งเตือน |
| เตือนล่วงหน้า (วัน) | ค่าเริ่มต้น 30 วัน |

สถานะคำนวณอัตโนมัติ: ยังไม่เริ่ม / มีผลอยู่ / ใกล้หมดอายุ / หมดอายุ

- ระบบส่งกิจกรรมเตือน **ครั้งเดียว** เมื่อเข้าช่วงเตือน ถ้าไม่มีผู้รับผิดชอบจะบันทึกข้อความใน chatter แทน
- ถ้าแก้วันสิ้นสุดหรือจำนวนวันเตือน (เช่น ต่ออายุ) ระบบเปิดการเตือนรอบใหม่ให้
- ถ้ารายการหนึ่งส่งเตือนไม่สำเร็จ ระบบ log ไว้และลองใหม่รอบถัดไป ไม่กระทบรายการอื่น

## 10. ตรวจนับทรัพย์สิน

การตรวจนับเป็นรอบ ระบบบันทึก **ข้อมูลที่คาดหวัง** (ผู้ถือครอง แผนก สถานที่) ของทรัพย์สินไว้ ณ ตอนเริ่ม ผลที่ตรวจพบจริงบันทึกแยก ไม่ไปแก้ข้อมูลทรัพย์สิน

### 10.1 สร้างและเริ่มรอบตรวจนับ (Officer)

1. Operations → **Audit** → New
2. ระบุ ชื่อรอบ วันที่ ผู้รับผิดชอบ และ **ขอบเขต**: แผนก สถานที่ตั้ง หมวดหมู่ (ไม่เลือก = ทั้งหมด)
3. กด **เริ่มตรวจนับ** ยืนยัน ระบบบันทึกข้อมูลคาดหวังของทรัพย์สินที่อนุมัติแล้วและยังไม่จำหน่ายตามขอบเขต **หลังเริ่มแล้วเปลี่ยนขอบเขตไม่ได้**

> ถ้าขอบเขตไม่ตรงกับทรัพย์สินใดเลย จะขึ้นข้อความ "ไม่พบทรัพย์สินตามขอบเขตที่เลือก" ให้ปรับขอบเขตก่อน (ทำได้ขณะเป็นร่าง)

### 10.2 บันทึกผลตรวจ

ในรอบที่ **กำลังตรวจนับ** มี 3 วิธี

**ก) ลิสต์บันทึกผลตรวจนับ (เร็วที่สุด)**
กดปุ่ม **บันทึกผลตรวจนับ** บนหัวฟอร์มรอบ ได้ลิสต์ที่แก้ไขในแถวได้ เลือกในคอลัมน์ **ผลการตรวจ** แล้วบันทึก

| เลือก | ผล |
|---|---|
| พบ | ระบบใส่สถานที่/ผู้ถือครองจริงเท่ากับที่คาดหวัง |
| ไม่พบ / สูญหาย / ชำรุด / เลิกใช้ | บันทึกผล |
| ยังไม่ตรวจ | ยกเลิกผลที่บันทึกไว้ (**เฉพาะ Officer ขึ้นไป**) |
| ผิดสถานที่ / ผิดผู้ถือครอง | ทำในลิสต์นี้ไม่ได้ ต้องไปฟอร์มรายการ เพราะต้องระบุสถานที่/ผู้ถือครองที่พบจริง |

คอลัมน์ **หมายเหตุ** แก้ได้ในลิสต์เดียวกัน ปุ่มลูกศรท้ายแถวเปิดฟอร์มรายการนั้น

**ข) ฟอร์มรายการตรวจนับ**
มีปุ่ม พบ, ไม่พบ, สูญหาย, ผิดสถานที่, ผิดผู้ถือครอง, ชำรุด, เลิกใช้ ใช้เมื่อต้องกรอกรายละเอียดเพิ่ม เช่น ผิดสถานที่ ให้ระบุ **สถานที่ที่พบจริง** (ต้องต่างจากที่คาดหวัง) ผิดผู้ถือครอง ให้ระบุ **ผู้ถือครองที่พบจริง** แนบรูปถ่ายและหมายเหตุได้

**ค) สแกน/ค้นหา**
กดปุ่ม **สแกน/ค้นหา** พิมพ์หรือสแกน รหัสทรัพย์สิน บาร์โค้ด หมายเลขเครื่อง หรือ URL/โทเคนจากป้าย QR ระบบเปิดฟอร์มรายการของทรัพย์สินนั้น (ใช้ได้กับเครื่องสแกนแบบ keyboard wedge) ถ้าสแกนทรัพย์สินที่อยู่นอกขอบเขตของรอบนี้ จะแจ้งว่าไม่พบ

### 10.3 จัดการรายการผิดปกติและปิดรอบ

- ผลที่ไม่ใช่ "พบ" นับเป็นรายการผิดปกติ Officer ระบุ **การแก้ไข** ในฟอร์มรายการ: โอนย้าย, แก้ไขข้อมูล, อยู่ระหว่างสอบสวน, จำหน่าย, ยอมรับตามที่พบ พร้อมรายละเอียด
- รายการ ผิดสถานที่/ผิดผู้ถือครอง มีปุ่ม **สร้างการโอนย้าย** เปิดใบโอนย้ายที่กรอกค่าให้แล้ว (Officer)
- **ปิดรอบตรวจนับ** (Manager) ได้เมื่อทุกรายการถูกตรวจแล้ว **และ** ทุกรายการผิดปกติระบุการแก้ไขแล้ว
- รอบที่ปิดแล้วหรือยกเลิกแล้วบันทึกผลเพิ่มไม่ได้ ลบได้เฉพาะรอบที่เป็นร่างหรือยกเลิก

แท็บ **รายการทรัพย์สิน** ในฟอร์มรอบเป็นภาพรวม (อ่านอย่างเดียว) แสดงผลของทุกรายการและสีตามผล ตัวเลข อัตราตรวจนับ ผิดปกติ และผิดปกติที่ยังไม่แก้ไข ดูได้ที่ฟอร์มรอบ

## 11. ป้าย QR

- พิมพ์ป้ายจากรายงาน **ป้าย QR ทรัพย์สิน** (เลือกทรัพย์สินที่ฟอร์มหรือในลิสต์ แล้วกด Print/พิมพ์; เห็นเฉพาะ Asset Officer ขึ้นไป) ได้ PDF ขนาด A4 ป้ายมีชื่อบริษัท รหัสทรัพย์สิน และ QR
- QR เป็น URL `.../buz_asset/qr/<โทเคน>` โทเคนเป็นรหัสสุ่มเฉพาะทรัพย์สิน **ไม่มีข้อมูลบัญชี**
- **ต้องเข้าสู่ระบบ** จึงจะเปิดได้ และใช้สิทธิ์ตามปกติ ผู้ที่ไม่มีสิทธิ์อ่านทรัพย์สินจะเห็น 404 เหมือนโทเคนที่ไม่มีอยู่จริง
- ถ้าทรัพย์สินนั้นมีรายการที่ยังไม่ตรวจในรอบตรวจนับที่กำลังดำเนินอยู่ การสแกนจะพาไปหน้ารายการตรวจนับนั้นโดยตรง (สะดวกสำหรับสแกนด้วยมือถือ) มิฉะนั้นเปิดฟอร์มทรัพย์สิน

## 12. จำหน่ายทรัพย์สิน

Accounting → **Disposal** → New (Officer)

| ฟิลด์ | ความหมาย |
|---|---|
| ทรัพย์สิน | ต้องอนุมัติแล้ว บันทึกเป็นสินทรัพย์แล้ว และยังไม่จำหน่าย |
| ประเภทการจำหน่าย | ขาย / ตัดจำหน่าย-ทิ้ง / สูญหาย |
| วันที่จำหน่าย | วันที่ของรายการบัญชี |
| เหตุผล | จำเป็น |
| ใบแจ้งหนี้ขาย | เฉพาะประเภทขาย ต้อง post แล้วและเป็นบริษัทเดียวกัน |

**ขั้นตอน:** ร่าง → **อนุมัติ** (Manager) → **ลงบัญชี** (Asset Accounting Manager)

**เงื่อนไขก่อนลงบัญชี**

- ค่าเสื่อมราคาของทุกงวดที่ถึงกำหนดภายในวันที่จำหน่าย **ต้องลงบัญชีครบก่อน** (งวดที่กลับรายการแล้วหรือยกเลิกแล้วไม่ถูกนับและไม่ขวาง)
- ทรัพย์สินหนึ่งรายการมีรายการจำหน่ายที่ไม่ยกเลิกได้ครั้งเดียว

**รายการบัญชีที่ระบบสร้าง**

| บรรทัด | ด้าน |
|---|---|
| บัญชีสินทรัพย์ถาวร (ราคาทุน) | เครดิต |
| บัญชีค่าเสื่อมราคาสะสม (ยอดที่ลงบัญชีแล้ว) | เดบิต |
| บัญชีพักการจำหน่าย (ถ้าขายและผูกใบแจ้งหนี้) | เดบิต |
| บัญชีกำไร/ขาดทุนจากการจำหน่าย | เดบิต (ขาดทุน) หรือ เครดิต (กำไร) |

**การขายและรายได้**: ระบบ **ไม่บันทึกรายได้ซ้ำ** ใบแจ้งหนี้ขายต้องลงรายได้ที่ **บัญชีพักการจำหน่าย** ของหมวดหมู่ รายการจำหน่ายจะปิดบัญชีพักนั้นเข้ากำไร/ขาดทุน ถ้าใบแจ้งหนี้ไม่มีรายการในบัญชีพักการจำหน่ายจะลงบัญชีไม่ได้ กำไร/ขาดทุน = ผลตอบแทนจากการขาย − มูลค่าตามบัญชี

**หลังลงบัญชี**: ทรัพย์สินเป็น "จำหน่ายแล้ว" งวดค่าเสื่อมที่ยังเป็น วางแผนไว้/ข้อยกเว้น ถูกยกเลิก มูลค่าตามบัญชีของทรัพย์สินเป็นศูนย์ ประวัติยังอยู่ครบ

**ข้อจำกัด:** รายการบัญชีจำหน่ายกลับรายการไม่ได้ และยังไม่รองรับการจำหน่ายบางส่วน/ส่วนประกอบ ถ้าวันที่จำหน่ายอยู่ในช่วงล็อกบัญชี การลงบัญชีถูกปฏิเสธ (รายการยังเป็น "อนุมัติแล้ว") ให้แก้วันที่หรือปลดล็อกก่อน

## 13. แดชบอร์ดและรายงาน

### 13.1 Dashboard

ตัวเลขสรุป ณ วันที่เลือก: จำนวนทรัพย์สิน ราคาทุน ค่าเสื่อมสะสม (ลงบัญชีแล้ว) มูลค่าตามบัญชี (NBV) ค่าเสื่อมรอลงบัญชี ประกัน/รับประกันที่ใกล้หมดอายุใน 30 วัน พร้อมกราฟมูลค่าตามเวลาและตามหมวดหมู่ กรองตามบริษัท แผนก หมวดหมู่ สถานที่ สถานะ ส่งออกเป็น Excel ได้ ข้อมูลทุกตัวมาจากรายการบัญชีที่ลงจริง (ค่าตามแผนแสดงแยก)

### 13.2 รายงาน (เมนู Reports)

| กลุ่ม | รายงาน | หมายเหตุ |
|---|---|---|
| Register & Value | Asset Register, Book Value, Asset Ageing, By Department, By Location | มุมมอง list / pivot / graph |
| Depreciation & Accounting | Depreciation, Depreciation Forecast, Asset Roll-forward, GL Reconciliation, Disposal | Roll-forward และ GL Reconciliation ใช้ได้เฉพาะ **Accountant** |
| Operations | Transfers, Maintenance Cost, Audit Results | |

**GL Reconciliation (กระทบยอดกับ GL)** — เลือก "ณ วันที่" แล้วกด **คำนวณ** ได้ตารางเทียบยอดบัญชี GL กับยอดทะเบียน แยกราคาทุนและค่าเสื่อมสะสมตามบัญชี ได้ผลต่างและสถานะ "ตรงกัน" แต่ละแถวมีปุ่ม **ดูรายการบัญชี** และ **ดูทรัพย์สิน** เพื่อไล่ที่มาของผลต่าง ค่าเสื่อมครบกำหนดที่ยังไม่ลงบัญชีแสดงแยกเป็นแผน ไม่ปนในยอดบัญชี หมวดหมู่ที่ยังไม่ตั้งบัญชีจะถูกรายงานแยก

> การจับคู่ใช้บัญชีปัจจุบันของหมวดหมู่ ถ้าเปลี่ยนบัญชีของหมวดหมู่ภายหลัง รายการเก่าจะแสดงเป็นผลต่างจนกว่าจะโอนบัญชี

**Asset Roll-forward** — เลือกช่วงวันที่ ได้ต่อหมวดหมู่: ราคาทุนต้นงวด + เพิ่มขึ้น − จำหน่าย = ปลายงวด และค่าเสื่อมสะสมต้นงวด + ค่าเสื่อมในงวด − ตัดจากการจำหน่าย = ปลายงวด พร้อมคอลัมน์ตรวจสอบผลต่าง (ควรเป็นศูนย์) "เพิ่มขึ้น" นับตามวันเริ่มใช้งาน ไม่ใช่วันที่ในใบแจ้งหนี้

**Asset Ageing** — แบ่งตามช่วงอายุนับจากวันเริ่มใช้งาน

## 14. ข้อควรระวังและแก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| กด บันทึกเป็นสินทรัพย์ ไม่ได้ / ขึ้น "ตั้งค่าบัญชีและสมุดรายวันไม่ครบ" | หมวดหมู่ยังไม่ตั้งบัญชีสินทรัพย์ ค่าเสื่อมสะสม ค่าใช้จ่าย หรือสมุดรายวัน | ตั้งค่าที่ Configuration → Asset Categories |
| ไม่เห็นปุ่มคำนวณตาราง/บันทึกเป็นสินทรัพย์ | ไม่ได้อยู่กลุ่ม Asset Accountant (Manager ไม่รวมสิทธิ์นี้) | เพิ่มกลุ่มให้ผู้ใช้ |
| ลงบัญชีค่าเสื่อมแล้วงวดเป็น **ข้อยกเว้น** | วันที่งวดอยู่ในช่วงล็อกบัญชี ผิดนโยบายวันที่ หรือบัญชี/สมุดรายวันเป็นของบริษัทอื่น อ่านข้อความที่แถวงวด | แก้ที่ต้นเหตุ แล้วกด **ลงบัญชี** ซ้ำที่งวดนั้น |
| ลงบัญชีงวดไม่ได้ "ต้องลงบัญชีงวด ... ก่อน" | มีงวดก่อนหน้ายังไม่ลงบัญชี | ลงบัญชีตามลำดับ |
| ลงบัญชีล่วงหน้าไม่ได้ | วันที่ของงวดยังไม่ถึง | รอถึงกำหนด |
| จำหน่ายไม่ได้ "ต้องลงบัญชีค่าเสื่อมราคาถึงวันที่จำหน่ายให้ครบก่อน" | มีงวดถึงกำหนดแต่ยังเป็น วางแผนไว้/ข้อยกเว้น | ลงบัญชีให้ครบ หรือกลับรายการแล้วคำนวณตารางที่เหลือใหม่ |
| คำนวณตารางค่าเสื่อมไม่ได้ "มีงวดที่ลงบัญชีหรือกลับรายการแล้ว" | มีงวดที่ลงบัญชีแล้ว | ใช้ **คำนวณตารางที่เหลือใหม่** |
| สร้างทรัพย์สินจากใบแจ้งหนี้ไม่ได้ ไม่มีปุ่ม | ใบแจ้งหนี้ยังไม่ post / ไม่ใช่ใบแจ้งหนี้ผู้ขาย / ไม่ใช่ Officer | ตรวจสถานะและสิทธิ์ |
| "จัดสรรรายการ ... เกินจำนวนที่เหลือ" | จัดสรรไปแล้วบางส่วน | ลดยอดให้ไม่เกินที่เหลือ |
| ตั้งใบแจ้งหนี้กลับเป็นร่างไม่ได้ | ถูกใช้สร้างทรัพย์สินแล้ว | ใช้ใบลดหนี้/กลับรายการ |
| แก้ผู้ถือครอง/สถานที่ของทรัพย์สินไม่ได้ | ทรัพย์สินอนุมัติแล้ว | ใช้ **โอนย้าย** |
| เริ่มตรวจนับไม่ได้ "ไม่พบทรัพย์สินตามขอบเขต" | ขอบเขตไม่ตรงกับทรัพย์สินที่อนุมัติแล้วและยังไม่จำหน่าย | แก้ขอบเขต (ขณะเป็นร่าง) |
| เลือก ผิดสถานที่ ในลิสต์แล้วไม่บันทึก | ต้องระบุสถานที่ที่พบจริง | ไปที่ฟอร์มรายการ (ปุ่มท้ายแถว) |
| ปิดรอบตรวจนับไม่ได้ | ยังมีรายการไม่ตรวจ หรือรายการผิดปกติที่ยังไม่ระบุการแก้ไข | ตรวจให้ครบและระบุการแก้ไข |
| สแกน QR แล้วขึ้น 404 | ไม่ได้ล็อกอิน หรือไม่มีสิทธิ์/บริษัทอื่น | ล็อกอินด้วยผู้ใช้ที่มีสิทธิ์ |
| กลับรายการค่าเสื่อมจากหน้ารายการบัญชีไม่ได้ | ไม่ใช่ Asset Accounting Manager หรือรายการกลับไม่ได้ post ทันที | ใช้ผู้ใช้ที่มีสิทธิ์ และเลือกให้ post ทันที |

### ข้อห้ามที่ระบบบังคับ

- แก้ สถานะ ของทรัพย์สิน/ใบโอนย้าย/การจำหน่าย ตรงๆ ไม่ได้ ต้องผ่านปุ่ม
- แก้หรือลบรายการบัญชีของทรัพย์สินที่ post แล้วไม่ได้ ใช้การกลับรายการ
- รายการบัญชีที่ตรงกับช่วงล็อกบัญชีจะไม่ถูกบังคับลง และไม่ถูกเลื่อนวันที่ให้

### ติดต่อผู้ดูแล

ปัญหาที่เกี่ยวกับการตั้งค่าบัญชี สิทธิ์ผู้ใช้ หรือยอดไม่ตรงกับ GL ให้แจ้งฝ่ายบัญชีและผู้ดูแลระบบพร้อมเลขที่ทรัพย์สิน (เช่น `AST/00461`) และข้อความ error ที่ขึ้น
