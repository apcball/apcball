## Volume (docker MOG_LIVE copy, 1,078 open WOs, 151 MOs)
- Compute 13.8 s: 1,551 products, 2,022 suggestions (1,298 buy / 724 make, levels 0–3), 404 late, 376 buy with no vendor at all.
- Demand: delivery 21,866 / forecast 33,573 (595 products) / dependent 338,143.
- Schedule 2.6 s: 0 overlaps, 348 WOs on history / 730 on expected. The queue runs to 2027-04-29, so capacity is heavily overloaded.
- Gantt `gantt_data` 0.1 s, 30 KB.
- Apply batch of 50 MOs takes 3.1 s (365 WOs). It re-dates 739 **open** raw/finished moves to the planned dates (expected Odoo behaviour) and 0 done moves.

- Wizard on real data (rolled back): 20 draft MOs with analytic + 1 draft PO. Non-draft stock moves, `mrp_stock_request`, quants and SVL counts are unchanged.
- Apply move chain: open MOs have no `move_orig_ids`/`move_dest_ids` or pickings, so nothing outside the MO's own moves changes.
